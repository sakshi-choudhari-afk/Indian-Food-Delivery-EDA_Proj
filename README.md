# Indian Food Delivery – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on analyzing an Indian food delivery dataset using Python. The objective is to explore delivery-time patterns, identify data quality issues, and understand the factors that may influence food delivery time.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Handle missing values and inconsistent data.
- Analyze delivery-time patterns.
- Visualize important trends and insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses an Indian Food Delivery dataset containing approximately 50,000 records. The dataset includes delivery-related information and customer, city, food category, and payment method fields.

## Project Workflow
1. Data loading and initial inspection
2. Data quality checks
3. Missing-value handling
4. Data cleaning and preprocessing
5. Exploratory data analysis
6. Data visualization
7. Interpretation of findings

## Key Analysis Areas
- Delivery-time distribution
- Delivery time across cities
- Food category analysis
- Payment method analysis
- Missing values and data quality

## Key Learnings
- Practiced data cleaning and preprocessing.
- Improved understanding of exploratory data analysis.
- Used Python libraries to analyze and visualize data.
- Developed skills in interpreting patterns in real-world datasets.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open the Jupyter Notebook.
4. Run the notebook cells in sequence.
